# Third-Party Notices

KOMET includes third-party open-source software. This file records the
production dependency licenses used by the workspace.

- Generated: 2026-10-23
- Source: `pnpm -r --prod licenses list --json`

  tooling is excluded.
- Regenerate after dependency changes with the same command.

This inventory is not a substitute for the license text. Before distributing a
build outside i3L, include the full license text and copyright notice from each
